# ShowBadgesInChat

Shows the message author's badges beside their name in chat.

When "Fetch profile badges" is enabled, the plugin uses the user's real profile
badge list — the exact list their profile popout shows — so it includes server
boosting, Nitro, Active Developer and anything Discord adds later. Until a
profile is fetched (or when fetching is disabled), it falls back to a local
flags-based list.
